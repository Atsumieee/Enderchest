# SQL – DDL (Data Definition Language)

## Überblick
_Platzhalter — Notiz wird noch erstellt._

DDL umfasst alle SQL-Befehle, die die **Struktur** einer Datenbank definieren: Tabellen erstellen, ändern, löschen. Ohne DDL gibt es keine Tabellen — und ohne Tabellen keine Daten.

Wichtigste Befehle: `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, `CREATE DATABASE`.
