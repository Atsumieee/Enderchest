# _Staging

Temporärer Eingangsbereich für Rohmaterial das noch verarbeitet werden muss.

## Verwendung
- PDFs, TXTs, kopierte Texte hier ablegen
- Claude verarbeitet sie auf Anfrage zu Obsidian-Notizen
- Nach Verarbeitung: Löschen oder nach `500 Ressources/` verschieben

## Namenskonvention
`[modul]-[thema]-[typ].txt` z.B. `m106-joins-unterlagen.txt`
