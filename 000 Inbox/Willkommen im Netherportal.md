# Willkommen im Netherportal

Dies ist ein persönlicher Wissensvault – verbunden mit Claude als Second Brain.

## Was dieser Vault ist

- **Netherportal** ist ein zentrales Wissensmanagementsystem für Schule, Arbeit und Privat
- Alle Notizen liegen als `.md` Dateien lokal und werden via OneDrive / Obsidian Sync auf alle Geräte synchronisiert
- Claude hat über die Desktop App direkten Lese- und Schreibzugriff auf diesen Vault

## Struktur

| Ordner | Zweck |
|---|---|
| `000 Inbox` | Schnelle Notizen, noch unsortiert |
| `100 Schule` | Modulzusammenfassungen, Projekte |
| `200 Arbeit` | Arbeitsdokumentation, Projekte |
| `300 Privat` | Persönliche Notizen |
| `400 Areas` | Dauerhaftes Wissen (kontextübergreifend) |
| `500 Resources` | Referenzmaterial, Links |
| `Templates` | Notiz-Vorlagen |
| `Archive` | Abgeschlossene Projekte |
