Frage: "Was ist die Hauptstadt von Frankreich?"  →  Antwort: "Paris"

Schritt 1 — Tokenisierung

Das Modell liest keinen Text. Zuerst wird der Text in Tokens zerlegt — kleine Wortfragmente. Jedes Sprachmodell hat ein festes Vokabular von ca. 50 000 bis 100 000 Tokens.

Die Frage zerlegt in Tokens:

Tokens sind nicht immer ganze Wörter — "Frankreich" könnte zu ["Frank", "reich"] werden. Häufige Wörter bleiben ganz, seltene werden aufgespalten.

Schritt 2 — Token-IDs

Jeder Token wird zu einer einzigen Zahl — seiner ID im Vokabular. Das ist wie ein Wörterbuch-Index. Das Modell kennt nur Zahlen, keine Buchstaben.

Vokabular-Grösse (typisch)
50 257

GPT-2 nutzt genau 50 257 Tokens. GPT-4 ~100 000.

Unsere Frage
8 Tokens

Jeder Token → eine Zahl zwischen 0 und 50 256.

Schritt 3 — Token-Embeddings

Jede Token-ID wird in einen Vektor umgewandelt — eine Liste von Zahlen (z.B. 768 Zahlen bei GPT-2). Das ist die erste echte Bedeutungs-Kodierung.

Token-ID 9703 → Embedding: [0.23, -0.41, 0.87, 0.12, -0.66, 0.34, ... ] (768 Werte)
Embedding-Dimension
768

Jeder Token wird zu einem Punkt im 768-dimensionalen Raum.

Ähnliche Wörter
nah beieinander

"König" und "Königin" liegen im Embedding-Raum nahe zusammen.

Schritt 4 — Forward Pass durch Transformer-Schichten

Die 8 Embedding-Vektoren fliessen durch viele Schichten. In jeder Schicht passieren zwei Dinge: Attention (Tokens schauen sich gegenseitig an) und Feed-Forward (jeder Token rechnet für sich).

A
Attention-Schicht

"Hauptstadt" schaut auf "Frankreich" — der Token lernt: ich muss eine Stadt nennen, die zu Frankreich gehört.

FF
Feed-Forward-Schicht

Das Wissen über Fakten steckt hier — "Frankreich" aktiviert Neuronen, die mit "Paris", "Eiffelturm", "EU" verknüpft sind.

×N
Das wiederholt sich

GPT-2: 12 Schichten. GPT-4: vermutlich ~120 Schichten. Jede Schicht verfeinert das Verständnis.

Schritt 5 — Output Logits & Softmax

Nach der letzten Schicht wird der Vektor des letzten Tokens in 50 257 Zahlen (Logits) umgewandelt — eine Bewertung für jeden möglichen nächsten Token. Softmax macht daraus Wahrscheinlichkeiten.

Schritt 6 — Vom Token zur Antwort

Das Modell wählt den wahrscheinlichsten Token, fügt ihn an die Eingabe an, und wiederholt alles — bis ein Stop-Token erscheint. So entsteht die Antwort Wort für Wort.

Antwort-Generierung Schritt für Schritt

Das Gesamtbild: Text → Zahlen (Tokens + Embeddings) → Neuronen-Shift durch viele Schichten → 50 000 Wahrscheinlichkeiten → höchster Wert → neuer Token → zurück zum Start — bis die Antwort vollständig ist.
